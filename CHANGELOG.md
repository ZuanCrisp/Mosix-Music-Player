# Changelog

## v1.0.0 - Mosix

First Mosix release baseline.

- Rebranded the application, Android package, project metadata, and documentation as Mosix.
- Removed the forced update requirement; update checks remain controlled by the app setting.
- Includes extension based music search and downloads, local playback and library management, playlists, lyrics, metadata editing, network storage access, and configurable audio output.
- Android Lite build is available for local APK testing.
