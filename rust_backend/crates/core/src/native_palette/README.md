`fixtures.json` was generated by the pinned Dart material_color_utilities
0.13.0 `QuantizerCelebi.quantize(pixels, 128)` implementation. It preserves
ordered color/population pairs and final Flutter Score seeds, not approximate
RGB tolerances. Each input is generated from its kind/count/LCG seed, avoiding
large raw artwork fixtures. Cases cover opaque noise, transparent pixels,
mixed alpha, colors sharing one Wu histogram bin (Dart seeded RNG fallback),
112×112 gradients and repeated equal-population colors.

The Rust port retains the upstream Apache-2.0 attribution. The seeded MWC
helper matches the Dart SDK VM's Random implementation (BSD-3-Clause).
